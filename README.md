# Смывы — рабочее место службы качества

Учёт и аналитика микробиологических смывов (контроль чистоты оборудования на производстве). Заменяет ручной Excel из 13 вкладок единым приложением: ввод, журнал по цехам и живая статистика.

## Состав

| Файл | Назначение |
|---|---|
| **smyvy.html** | Приложение целиком (ввод · журнал · статистика). Работает офлайн, данные в браузере. |
| **server.py** | Серверная часть для продакшена: вход по паролю, роли, аудит, БД (SQLite), импорт истории. |
| **README_SERVER.md** | Чек-лист развёртывания на сервере (HTTPS, бэкапы, роли, безопасность). |
| **parser.py** | Разбор исходного Excel в чистую типизированную базу. |
| **Запустить.bat** | Локальный запуск: поднимает сервер на `http://localhost:8000` и открывает браузер. |
| **07. Результаты смывов 2026.xlsx** | Исходный журнал смыв (историческая база). |

## Запуск (локально)

Двойной клик по **Запустить.bat** → откроется `http://localhost:8000/smyvy.html`.
Либо вручную в папке проекта:
```
python -m http.server 8000
```

Вход по паролю (меняется в `smyvy.html`, константа `APP_PASSWORD`).

## Что умеет приложение

- **Ввод** — выбор цеха подставляет точки отбора и нужные показатели; значения из списка (без опечаток), мгновенная проверка на превышение норматива.
- **Журнал** — вся история + новые записи; фильтры по статусу и цехам (с числами), поиск, правка/удаление своих записей, резервные копии, выгрузка в Excel (листы по цехам).
- **Статистика** — KPI, динамика по месяцам, очаг микрофлоры, охват показателей, тренд соответствия, матрица «цех × показатель», топ проблемных точек, повторные нарушители, регулярность контроля. Всё пересчитывается вживую.

## Показатели и нормы

КМАФАнМ (лимит 1×10³ КОЕ/см²), БГКП, Proteus, Salmonella, Listeria, Staph, Плесень, Дрожжи.
Статусы: **норма** · **повышенный** (рост КМАФАнМ в пределах нормы) · **превышение** (КМАФАнМ выше норматива) · **несоответствие** (бактерии обнаружены).
