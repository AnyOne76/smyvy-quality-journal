# Смывы — рабочее место службы качества

Учёт и аналитика микробиологических смывов (контроль чистоты оборудования на производстве). Заменяет ручной Excel из 13 вкладок единым приложением: ввод, журнал по цехам и живая статистика.

## Состав

| Файл | Назначение |
|---|---|
| **smyvy.html** | Приложение (ввод · журнал · статистика · ИИ · админ-панель). |
| **app_server.py** | Основной локальный/внутренний сервер: вход, роли, сессии, админка, ИИ-прокси, email-уведомления. |
| **Запустить.bat** | Запуск `app_server.py` и открытие приложения в браузере. |
| **server.py** | Заготовка продакшен-сервера (общая БД журнала, импорт истории). См. `README_SERVER.md`. |
| **parser.py** | Разбор исходного Excel в типизированную базу. |
| **refresh_embedded_history.py** | Обновление встроенной истории в `smyvy.html` из Excel. |
| **.smtp_config.example** | Пример настроек SMTP для уведомлений администраторам. |
| **07. Результаты смывов 2026.xlsx** | Исходный журнал смывов (историческая база). |

## Запуск (локально)

Двойной клик по **Запустить.bat** → `http://localhost:8000/smyvy.html`.

Или вручную:
```
python app_server.py
```

Первый зарегистрированный пользователь становится администратором. Остальным роль назначает админ.

## Учётные записи и роли

- При регистрации сотрудник указывает **email, пароль и ФИО**.
- Роль назначает **администратор** после регистрации.
- Ответственный в новых записях подставляется из учётной записи.
- Роли:
  - `pending` — ожидает назначения роли;
  - `viewer` — только просмотр;
  - `master` — ввод записей;
  - `quality` — ввод + редактирование/удаление;
  - `admin` — всё + управление пользователями.

## Email-уведомления

При новой регистрации письмо уходит **всем активным администраторам** (email = логин учётки).

1. Скопируйте `.smtp_config.example` → `.smtp_config`
2. Укажите пароль приложения Gmail (или другой SMTP)
3. Проверка: `python app_server.py testmail`

Файл `.smtp_config` в `.gitignore` — в репозиторий не попадает.

## ИИ-помощник

Прокси к **DeepSeek** (модель `deepseek-chat`) встроен в `app_server.py`.

1. Скопируйте `.ai_key.example` → `.ai_key`
2. Вставьте API-ключ DeepSeek одной строкой ([platform.deepseek.com](https://platform.deepseek.com/api_keys))
3. Перезапустите `Запустить.bat`

Без ключа вкладка ИИ недоступна, остальное работает. Файл `.ai_key` в `.gitignore`.

## Показатели и нормы

КМАФАнМ (лимит 1×10³ КОЕ/см²), БГКП, Proteus, Salmonella, Listeria, Staph, Плесень, Дрожжи.  
Статусы: **норма** · **повышенный** · **превышение** · **несоответствие**.

## Что умеет приложение

- **Ввод** — цех подставляет точки и показатели; проверка норматива сразу.
- **Журнал** — фильтры, поиск, правка/удаление по роли, резервные копии, выгрузка в Excel.
- **Статистика** — KPI, динамика, drill-down, тепловая карта, проблемные точки.
- **Админ** — пользователи, роли, блокировка.
- **ИИ** — чат по данным, отчёт, рекомендации по несоответствиям.
